# v7 설계 — 슬롯 강화 · 스테이지 지도 (2026-11-07)

## 1. 슬롯 강화 (schema 6)
선배 요청: "아이템이 변경되면 강화레벨이 초기화되어서 번거로워" → 강화는 **장착 슬롯**에 붙습니다.

- 슬롯 8칸: 무기·투구·갑옷·장갑·신발·목걸이·반지 1·반지 2 (반지는 칸마다 따로).
- 장비를 바꿔도 단계가 남고, 빈 슬롯도 미리 강화할 수 있습니다(나중에 끼우는 장비에 적용).
- 능력치: 장비 기본 능력치 × (1 + 5% × 슬롯 단계). 옵션·세트는 영향 없음.
- 규칙 유지: 최대 +15, +1~+5 100%, +6~+10 70→30%, +11~+15 20→5%, 실패 시 +10 이하 유지 · +11 이상 1단계 하락, 파괴 없음.
- 비용: 슬롯 단계만으로 정함 `floor(5 × 1.42^단계 × 1.5)` (예전 등급 배수 1.0–2.25 대신 고정 1.5).
- 분해: 등급 기본값만(강화 광석은 슬롯에 남아 있으므로 환급 없음).
- 저장: `state.slotEnhance{슬롯: 단계}`, `state.slotEnhanceOre{슬롯: 투입 광석}`, 아이템의 `enhance`·`oreInvested` 필드 삭제.
- 이전(5 → 6): 각 슬롯 = 그 슬롯에 장착 중이던 장비의 강화 단계. 장착하지 않은 장비(보관함·임시 보관함)의 투입 광석은 **100% 환급**하고 초기화. 강화 흔적이 있으면 `notices.slotEnhance{refund, refunded, levels}`를 남겨 로드 후 한 번 안내 창을 띄우고, 확인하면 지웁니다(트랜잭션).
- 화면
  - 장비 탭: 장착 칸에만 `+N`, 보관함 타일은 단계 표시 없음. 빈 칸을 누르면 그 슬롯 강화, "슬롯 강화" 버튼, 장착 칸 → 비교 → "〈슬롯〉 강화 +N".
  - 강화 창: 8슬롯 칩(단계 표시)으로 바꿔 가며 강화, 장착 장비의 전/후 능력치, 기본 능력치 보너스 +N% → +N+5%.
  - 비교 창: 두 장비 모두 대상 슬롯 단계가 적용된 값 + "슬롯 강화 +N이 두 장비 모두에 적용" 안내.
- 영향 없음: 뽑기·드롭·자동 성장 예약 골드·신화 제작·도감(아이템에 강화가 없으니 새 아이템은 그대로).

## 2. 스테이지 지도 (schema 7)
선배 요청: "스테이지와 맵이 있어서 하나씩 깨는 재미" → 기존 웨이브 1–10을 **스테이지 1-1 … 1-10**으로 보여 주고, 지역마다 보스 노드를 둡니다.

- 여는 곳: 전투 화면 위 지역 칩(이름 + `2-3`), 모험 탭 "스테이지 지도", 메뉴 타일. 예전 "지역 선택" 창을 대체합니다.
- 화면: 지역 배경 위에 굽이치는 길(SVG) + 노드 11개(DOM 버튼 40px, 보스 56px). 클리어 ✓·별, 진행 중(맥동, 동작 줄이기면 고정 테두리), 잠김 🔒. 지역 탭 10개(잠김 🔒, 별 합계), 잠긴 지역은 회색 + "〈보스〉 처치 시 열림".
- 노드를 누르면 아래 상세: 적 레벨·몬스터, 별 조건, 최초 클리어 보상(받았으면 "받음 ✓"), "여기서 사냥" / "보스 도전·재도전". 잘못 눌러 사냥터가 바뀌지 않도록 선택 → 버튼 2단계입니다.
- 클리어 규칙: 기존 그대로(그 웨이브에서 적 10마리 처치). 보스 처치 → 다음 지역 개방도 그대로.
- 별(최고 기록 저장, 환생해도 유지): ★ 클리어 · ★★ 그 스테이지에서 사망 없음 · ★★★ 사망 없음 + 30초 안(전투 시간). 보스: 처치 ★★, 45초 안 ★★★.
- 최초 클리어 보상(스테이지마다 1회, 자체 트랜잭션 `stageClear` 또는 보스 결과 트랜잭션 안에서): 보석 5(5·10번째 10) · 광석 3+2×지역 · 골드 = 그 레벨 처치 10마리. 보스 노드: 보석 30+10×지역 · 광석 20+10×지역 · 골드 30마리분(기존 보스 최초 처치 보상에 더해짐). 토스트는 저장이 끝난 뒤에만 뜹니다.
- 클리어 기록은 저장 중(busy)이면 대기열에 남았다가 다음 루프에서 저장합니다(버리지 않음). 더 얻을 게 없는 재클리어(보상 받음 + 별 같거나 낮음)는 저장하지 않습니다.
- "다음 스테이지 자동 진행" 토글(기본 켬) = `stages.auto` = 기존 `progression.autoAdvance`. 끄면 고른 스테이지에서 계속 사냥.
- 저장: `state.stages{stars{지역-번호: 1..3}, claimed{…: true}, auto}`. 이전(6 → 7): 이미 지난 스테이지·처치한 보스는 ★1 + 보상 받은 것으로 표시(소급 지급 없음).
- 레이아웃: 노드 좌표는 지도 상자 % 기준, 지도 높이 `clamp(300px, 100dvh − 360px, 540px)` — 390×844 / 360×700 / 412×915에서 노드 겹침 0, 상자 밖 0(`tools/qa_v7.cjs`).
- 그림: 지금은 전투 배경을 세로로 잘라 씀. 세로 지도 그림은 `docs/GPT_REQUEST.md` I 묶음으로 요청(같은 좌표에 길).
