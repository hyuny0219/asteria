# 디자인·화면 명세 v3 — NOCTURNE
2026-11-05. v1 도트 규격을 대체한다. 게임 시스템은01_IMPLEMENTATION.md를 따른다.

## 1. 핵심 인상
성숙한 성인 여성 히로인, 고딕 성당, 흑장미, 별자리의 서약. 매끄러운 애니메이션풍 일러스트, 고급스러운 검정·와인·금속 장식. 의상·자신감 있는 표정·조명으로 관능적인 분위기를 표현한다. 캐릭터별 나이·얼굴·의상 기준은04_CHARACTERS.md. 과거 치비/도트/양피지 시안은 사용하지 않는다.
기존 메인 원화·8키 포즈와 v3 신규 승급2종·일반6종·보스3종·배경3장·아이콘32개·UI22화면을 제공한다. 완성 전투 애니메이션·리깅은 후속 작업이며 모션 참고와 실제 상태를 구분한다. 원화가 캐릭터 가챠나 연애시스템을 뜻하지 않는다.

## 2. 스타일 가이드
`design/styleguide.html`, `design/tokens.json`, `08_UI_AND_EFFECTS.md`가 최신 규격이다. 본문16px, 보조14px, 터치44px 이상, 카드10px 반경, 화면 좌우16px. 일반/고급/희귀는 명칭·I/II/III·색으로 구분한다.

## 3. 메인 레이아웃
최신 높이 표는 `08_UI_AND_EFFECTS.md`의 390×844 구성을 적용한다. 전투 영역220px, 하단은 성장·장비·스킬·던전·메뉴. 전투/캐릭터 모드는 같은 영역과 시뮬레이션을 공유한다. 보스 도전 시 실제 전투로 전환하고 전투 상태를 초기화하지 않는다. 360×700은 스크롤로 대응하며 글자를 일괄 축소하지 않는다.

## 4. 화면별 계약
### S01 메인·히로인 / MVP
원화에서 얼굴과 의상 상단이 보이고 왼쪽아래에 세린/흑장미의서약. 상태정보는 인물 얼굴을 가리지 않는다. 스테이지·스킬·성장 규칙은01명세. 공격/체력/방어3행을 먼저 보이고 치명/속도는 목록스크롤로 접근. 아래 항목이 있음을 스크롤바·일부행으로 안내. ×1/10/100/MAX 실제비용·수량 표시. 현재 자동사냥 중임을 표기. 배속은 실제전투모드에서 조절. Lv30각성조건으로 이동.
### S02 장비 / MVP
4부위장착, 주스탯비교, 추천장착, 인벤토리4열(360px에서 필요 시3열). 검·금속갑옷·보석의 재질 구분. 디폴트 원화복장은 장비교체마다 자동 변경하지 않고, 승급/전용외형만 변경하여 제작범위 관리. 잠금/장착 보호, 일괄분해확인, 빈목록/초과보관 상태 필요.
### S03 스킬 / MVP
4+1슬롯, 궁극기 자동 OFF/정예보스/항상, 쿨타임/계수/효과 설명. 스킬아이콘은 와인빛 검흔·방패·별문장으로 제작. v3에서 스킬6개·상태2개 원화를 추가했으며 최종 개별 크롭 검수 후 적용한다. 범용아이콘을 모든스킬에 똑같이 쓰지 않는다. 일반3에서 승급후4, 스킬북구매 없음.
### S04 던전 / MVP+확장
첫 재료던전 활성, 골드/최종레이드는 후속. 별의 채석장은 신규 폐광 배경을 재사용하고 던전 표식으로 구분. 최고단계·보상·입장권·입장/소탕. 기록없으면 소탕사유 표시, 티켓0이면 충전시간 안내. 그림이 결과정보를 가리지 않게 한다.
### S05 별의 유산(장비 소환) / 확장
장비11개 결과4열, 등급/NEW/중복처리내역.72/200은 테스트천장 예시. 확률/최종상품표는 서버상품정의 후 적용. 캐릭터4인라인업을 소환캐릭터목록으로 사용하지 않는다. 예산·반복횟수·전설이상정지 필수. 실제결제/광고는 MVP미포함.
### S06 복귀보상 / MVP
세린의짧은 환영과원화 배너, 실제경과·적용시간·12시간상한, 골드/EXP/재료·장비내역. '보상받기'가 주행동. 광고+25%는후속. 친밀도/성적보상/노출해금 연결 없음. 원화전신 중 신체특정부위만 확대하지 않고 얼굴·장비가 함께보이는 구도. 지급저장후 연출, 중복지급 방지.
### S07 서약각성 / MVP
시스템승급을 화면에서 '서약각성'이라 부른다. 세린→흑장미기사/진홍의집행자. 나이·얼굴·머리색은 동일, 무기/갑옷/자세가 변화. v3 시안은 신규 승급2종 원화로 교체했다. 분기 전투 프레임은 아직 제작 대상이다. 조건완료·미완료·바로가기·EXP보관·자동시련을 표시. 미충족 조건과 실제 부족 수량 표시. 최초분기전환무료.

두제작경로: MVP는 손그림프레임 애니메이션, 확장은 컷아웃리깅 가능. 상용리깅런타임을 선택하면 라이선스·실행환경을 먼저 확인하고 임의도입하지 않는다. 리깅이 없어도 프레임 기반으로완료가능.
프레임기본: 대기6×160ms, 걷기8×90ms, 공격8(준비100/타격60/회수100ms안팎), 스킬8×80~120ms, 피격3×80ms, 사망6×100ms, 승리6×120ms. 논리피해는frame/event기준, 화면FPS와분리. 컷아웃은 같은상태/event를시간곡선으로표현.
384×512셀8프레임은4열×2행=1536×1024, RGBA디코드약6MiB/시트. 모든상태·모든캐릭터를동시에로딩하지 않는다. 활성캐릭터와적만선로딩, inactive언로드, 아틀라스한변2048px이하를초기기준으로측정. WebP압축은전송량을줄여도디코드메모리를같이줄이지는않는다.
접지점기본(192,480), 메타데이터에pivot/frames/durations/events/weaponSocket 명시. 옷·머리카락·검끝이셀밖으로잘리지않게여유. 실제알파영역을확인하고검정테두리halo방지. 좌우반전시방패·무기·가르마비대칭확인.

## 6. 렌더링·최적화
imageSmoothingEnabled=true, 필요시imageSmoothingQuality='high'. CSS image-rendering:auto. 정수배율제약과pixelated금지. DPR에따라 backing store설정, 저사양은DPR상한1.5~2를측정후설정. 매프레임이미지디코드/필터/대형블러금지. 배경캐시·파티클풀·동시이펙트상한. 원화로딩전스켈레톤, 실패시캐릭터명과재시도버튼.
모바일Canvas는큰일러스트를그대로매프레임전체리사이즈하지않고표시크기캐시사용. 앱진입필수아트목표1~3MB수준으로파생본최적화. 제공원본은편집용이며10MB폰트·고해상도이미지를그대로초기번들에넣지않는다. 폰트는WOFF2서브셋을정식빌드에서제작하고라이선스고지보존.
메뉴/목록은DOM, 텍스트스케일·포커스·키보드·모달focus관리. 중요본문16px, 보조14px. 리뷰HTML은정보를한화면에보여주기위해12px보조라벨이있으며최종게임은재배치한다.
