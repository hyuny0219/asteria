# 아스테리아 연대기 — NOCTURNE v3 디자인 인계

현재 MVP에 필요한 디자인 전반을 검토하고, 누락된 몬스터·보스·승급·장비·스킬·배경·UI 상태를 추가한 통합 패키지입니다. **디자인 원화와 동작 참고를 갖춘 제작 인계서이며 완성 게임/완성 애니메이션 패키지는 아닙니다.**

## 먼저 보기
1. `design/overview_v3.png` — 주요 화면 모음
2. `design/review.html` — 22개 화면/상태, 정적 UI 시안
3. `design/catalog.html` — 신규 원화·아이콘·배경 도감
4. `design/combat.html` — 신규 적 9종과 배경 3개를 선택하는 전투 모션 시연
5. `design/styleguide.html` / `.png` — 한 페이지 스타일 가이드
6. `CLAUDE_START.md` → `ASTERIA_COMPLETE_HANDOFF_V3.md` — 제작 시작

압축을 **모두 해제한 뒤** HTML을 브라우저에서 엽니다. 폰트·이미지는 동봉되어 있으며 네트워크 연결이 필요하지 않습니다. 일부 브라우저의 파일 보안 정책으로 로컬 자원이 차단되면 해당 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/design/review.html`로 확인합니다. 외부 공개 서버는 필요하지 않습니다.

## 이번 신규 제작
- 일반 몬스터 6종, 지역 보스 3종
- 세린 첫 승급 외형 2종: 흑장미 기사 / 진홍의 집행자
- 장비·재화·보상 아이콘 24개, 스킬·상태 아이콘 8개
- 별빛 초원·고대 사막·잊힌 폐광 배경 3장
- UI 22개 화면/상태, SVG 시스템 아이콘16개, 워드마크, 버튼 상태, 스타일 가이드
- 전투 배치/모션 HTML, 디자인 감사·보스 명세·연출 타이밍·에셋 목록·검수 결과

기존 세린 메인 원화, 4인 캐릭터 방향, 8키 포즈, 12초 MP4와 재현 소스도 포함합니다. MP4는 v2.1 당시 시연이며, **새 몬스터를 적용한 최신 움직임은 design/combat.html**이며 `motion/Asteria_v3_Boss_12s.mp4`로도 볼 수 있습니다.

## 구현 범위와 우선순위
세린(28세) 전사 1종, Lv1–35, 3지역·3보스·재료 던전1종·첫 승급2갈래. 자동 전투·성장·방치·저장·장비·승급을 연결합니다. 실제 광고/결제/장비 소환은 MVP에 없습니다. 확장 캐릭터와 Lv100 콘텐츠는 미완성 백로그로 표시했습니다.

문서 충돌 시 `CLAUDE_START.md` → 신규 `spec/06~08` → 기존 `spec/01~05` → tokens → review/catalog/combat → 과거 preview 순으로 적용합니다. v3에서 버서커의 무기는 **양손 대검**으로 통일했습니다. `archive`의 통합 문서는 과거 기록입니다.

## 에셋 준비 상태
`art/atlases`는 컨셉 보드입니다. 투명 PNG이지만 최종 게임용 패킹/피벗/히트박스는 아닙니다. 일부 셀 경계의 무기·효과를 정리하고 개별 추출해야 합니다. `art/asset_manifest.json`에 상태와 규격을 기록했습니다. 승급 전투 시트·몬스터 연속 프레임·완성 리깅은 후속 제작 대상입니다. 단일 그림을 움직인 시연을 완성 애니메이션이라고 부르지 않습니다.
