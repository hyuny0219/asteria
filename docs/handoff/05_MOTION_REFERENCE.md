# 05. 세린 전투 모션 레퍼런스 v2.1

## 추가된 결과물
- `motion/Serin_Combat_Motion_12s.mp4`: 세로720×1280,30fps,12초 동작 샘플. 검격·피격·스킬·승리 효과음 포함, 음성·음악 없음.
- `motion/motion_demo.html`: 로컬 브라우저에서 재생·일시정지·1프레임 이동·동작별 바로가기.
- `motion/assets/serin_poses.png`: 투명8포즈 원본 아틀라스1536×1024.
- `motion/assets/cathedral_stage.png`: 캐릭터 없는 성당 배경.
- `motion/atlas.json`:4열×2행, 셀384×512, 각 포즈의 소스좌표·접지점.
- `motion/timeline.json`: 모션 이벤트 시간·출력 규격.
- `motion/source/render_motion.py`: 순수 시간 기반 렌더·효과음 합성·FFmpeg 인코딩 코드.
- `motion/frame_*.png`: 핵심 타이밍의 화면.

## 이 샘플이 증명하는 것과 남은 작업
서로 다른8포즈를 전환하고 루트좌표를 이동시키므로 한 장의 일러스트만 흔드는 영상이 아니다. 대기·접근·공격 준비·찌르기·회수·피격·시전·승리의 주요 자세를 확인할 수 있다.
그러나 각 상태의 모든 중간 프레임을 그린 완성 애니메이션이나 스켈레탈 리깅은 아니다. 접근은2포즈 교대와루트 이동으로 만든 예시이며 실제 보행·호흡·머리카락·의복의 변형은 추가 제작해야 한다. 포즈 전환의 작은 실루엣/키 차이·손/무기 연속성은 최종 원화 단계에서 수정한다. 상태별 권장 프레임 수는02_DESIGN.md를 유지한다.
영상은 프레임 타이밍과 연출 전달용이며 완성 게임의 플레이 캡처가 아니다. 단순 마력표적은 전투 판독 테스트용 기하학적 목표물이며 최종 몬스터 디자인이 아니다. 실제전투·저장·골드 보상·랜덤은 연결되어 있지 않다.

## 실제 엔진 연결 계약
1. 캐릭터는동작ID/로컬시간/월드X/월드Y를 가진다. 스프라이트선택과그리기는렌더링만 담당한다.
2. 렌더프레임을보고데미지를즉석생성하지 않는다. combat action의hit event가피해와시각이펙트 양쪽을같은시각에발행한다.
3. 샘플시간은1배속 기준. 실제공격속도 변화는준비/회수시간을조정하되최소시간보장, hit event는항상1회.
4. 대기는반복, 공격/피격/시전/승리는원샷. 취소가능구간과피격우선순위를정의한다.
5. 접지점은포즈마다다르므로atlas.json의pivot 사용. 셀중심을무조건발위치로쓰지 않는다.
6. 이미지스무딩true. 투명 PNG의RGB 배경색은알파0이면표시하지 않는다. 배경제거를또할필요없다.
7. 포즈를전체384×512로사용하고성별·나이·얼굴·의상동일성유지. 신체부위만강조하는카메라로교체하지 않는다.
8. 최종게임에는이영상파일을전투대신재생하지 않는다. 원본/메타데이터와동작정의를참고해실제상태머신을구현한다.

## 렌더 재현
Python3, Pillow, numpy, FFmpeg/ffprobe가 필요하다. 패키지루트 기준:
`python motion/source/render_motion.py`
스크립트는motion폴더에MP4/WAV/스냅샷/메타데이터를생성한다. 난수는효과음합성에고정시드44 사용. 시각은절대시간함수이며프레임360장. 재렌더는동명미디어를덮어쓰므로수정전복사본보관.

## 납품 전 검수
실제아틀라스RGBA/1536×1024 확인. 인코딩된MP4길이·프레임수·해상도·디코드오류는render_metadata 및DESIGN_VALIDATION에기록. 핵심타격·피격·승리샷을검사한다. 실제게임이나실기기검증으로오인하지 않는다.
