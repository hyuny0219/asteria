# 몬스터·보스·지역 아트 사양 v3

## 공통 규칙
- 영웅은 왼쪽에서 오른쪽, 적은 오른쪽에서 왼쪽을 향한다. 단순 좌우 반전 시 무기 손과 문양 방향 검수.
- 게임 플레이 전투 영역 390×220~280 CSS px. 영웅 높이 120~150px, 일반 적 55~120px, 보스 150~200px. 체력바·피해 숫자는 실루엣과 겹치지 않게 위쪽 안전 공간 확보.
- 원화 보드의 투명 영역까지 포함한 크기와 실제 몸체 높이는 다르다. 최종 에셋은 투명 테두리를 측정하여 몸체 기준으로 맞춘다.
- 지상 적 피벗은 발바닥 중심, 비행 망령은 지면 그림자 중심. 적마다 피격 박스는 시각 크기와 별개로 JSON에 저장한다.
- 적의 공격 강도는 빨강만으로 표현하지 않는다. 바닥 선·확장 원·예고 아이콘·효과음 조합. 화면 가장자리에서도 읽혀야 한다.

프레임 수는 작업량 산정을 위한 목표다. 키 프레임 리깅으로 구현해도 같은 예고/접촉/복귀 시간과 실루엣을 유지하면 된다. 논리 피해 판정은 프레임 인덱스나 requestAnimationFrame 횟수에 의존하지 않는다. 보스 사망은 완료 1회만 이벤트를 발생시키고 자동 파밍 복귀가 UI 연출 종료에 종속되지 않게 한다.

## 그림자·정예·시련
정예는 외곽선 2px + 작은 마름모 배지 + “정예” 텍스트를 사용한다. 일반 몬스터 본체를 빨갛게 덮거나 2배 확대하지 않는다. 체력바 아래 특성 한 줄만 표시한다.

교관 분신은 별도 인간 NPC 수집 콘텐츠가 아니다. 기존 세린의 훈련 동작을 은색 단색·옅은 투명도·고유 이름표로 표시하는 투영체로 정의한다. 정적 원화에 CSS filter만 주고 별도 완성 캐릭터라고 집계하지 않는다.

## 배경 구현
meadow/desert/mine PNG는 각 1536×1024. 전투 화면에 cover 방식으로 표시하되 바닥 접지선은 뷰포트 높이의 약 80%에 고정한다. 보스 선택·지도 카드에는 별도 크롭을 사용한다. 반복 타일로 만들지 않았으므로 가로로 무한 연결하지 말고, 필요하면 카메라 팬을 24px 이하로 제한한다. 패럴랙스를 원하면 먼 배경/중경/바닥을 원본 단계에서 분리 제작해야 한다.

## 에셋 상태
`art/atlases/*`는 보드 원화다. `design/system/asset_regions.json`은 검토 뷰어용 영역이며 완성 스프라이트 패킹 결과가 아니다. 특히 보스의 무기/망토가 경계에 가까우므로 개체별 마스크 검수가 필요하다. 미검수 영역은 구현자가 조용히 런타임 완성으로 처리하지 말고 known_issues에 기록한다.
