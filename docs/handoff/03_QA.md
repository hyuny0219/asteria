# 개발 완료·검수 기준

## 단계별 산출
A: 전투1회+강화+저장+복귀가 연결된 실행본. B: 장비/스킬/보스/패배복귀. C: 승급/3지역/던전/아트. D: 테스트·수치보고·실기기·납품.
MVP 통과 전 확장콘텐츠·BM·멀티플레이 개발하지 않는다. 데이터 튜닝은 승인대기 없이 진행하되 변경 이유를 남긴다.

## 기능 검수 (각 PASS/FAIL/미검증 기록)
- [ ] 신규 사용자 첫60초 안 골드강화 가능, 첫10분 안 첫보스 접근
- [ ] 일반 사냥→보스 실패→정상파밍 자동복귀
- [ ] 15/30/60FPS에서 같은시간 전투결과가 허용 오차 내 동일 (RNG seed 고정)
- [ ] 다단히트/광역에서 궁극기 충전 상한 동작
- [ ] 공격속도·치명 상한 초과구매 불가, 재화 마이너스 없음
- [ ] ×10/MAX 수량·비용·실제차감 일치, 부족액 정확
- [ ] 장착/잠금 아이템 일괄분해 불가; 환급80% 내림·중복환급 없음
- [ ] 장비가득/방치20개초과 때 보관·전환내역 명시
- [ ] 스킬4+궁극기1, 기본미해금칸 조건 표시
- [ ] Lv30 EXP보관→승급→순차적용, 만렙35 처리 구분
- [ ] 증표부족/보스미클리어/시련실패 각각 이유·바로가기
- [ ] 자동시련만으로도 승급 가능, 실패재료차감 없음
- [ ] 두갈래로 동일보스 클리어 가능, 하나만 압도적으로 유리하지 않음
- [ ] 던전 소탕은 최고클리어단계 이하, 입장권정산·날짜경계·9개상한

## 저장·보상 오류 검수
- [ ] 경과0초/1시간/12시간/24시간/시계역행 테스트
- [ ] 24시간 경과 시12시간분 지급, 손실시간 명시
- [ ] 오프라인은 ×1·일시버프제외·효율75%, EXP/골드/재료 반올림 일관
- [ ] 검증하지 않은 마지막 보스나 새지역으로 수익이 뛰지 않음
- [ ] 보상받기 더블탭/새로고침/창닫기/두탭으로 중복지급 없음
- [ ] 숨김복귀 보상과 누적전투 dt를 둘다 적용하지 않음
- [ ] 소비직후 강제종료, 세이브손상, schema migration, 이전정상본복구
- [ ] 저장거부/용량부족 시 오류 표시, '저장됨' 오표시 금지
- [ ] 개발도구로 수정가능한 로컬저장을 보안완료라고 주장하지 않음

## UI·아트 검수
- [ ] 390×844·360×700·412×915 가로넘침 없음, 중요 버튼 접근 가능
- [ ] 최종 게임 버튼48px, 본문16px, 보조14px 이상 (시안 보조12px는 구현 시 개선), 한국어 잘림 없음
- [ ] 200% 텍스트 확대에서 주요정보·버튼 접근 (스크롤 허용)
- [ ] 모달 포커스, 키보드 탐색, 음소거, 감소된 모션
- [ ] 등급을 흑백에서도 배지·이름으로 구분
- [ ] 화살표·동작·접지점 정상, 비도트 전투 그림의 축척·윤곽 품질 일관
- [ ] PNG시안과 실제 UI 차이가 의도된 것인지 차이목록 기록
- [ ] 브라우저 닫힘·백그라운드·저전력에서 복귀 정상
- [ ] 실제 iOS Safari / Android Chrome 검증 여부를 각각 명시

## 밸런스 보고
seed 고정 테스트 + Monte Carlo로 레벨별 TTK, 보스성공률, 다음강화 대기, 첫승급시간, 장비드롭시간 분포를 기록. 원안 몬스터HP는30레벨마다약30배 성장하므로 플레이어성장과 함께 검토. 소환·강화실패는 MVP미포함이므로 '검증완료'에 포함하지 않는다.
초기 목표는 실험 가설이다. D1/D7/D30은 실제유저코호트가 없으면 예측값·추정값으로도 단정하지 않는다.

## 후속 출시 차단 조건
실결제/광고/랭킹을 넣기 전 서버재화검증·지급멱등성·계정복구·시간정산·실패대응·상품표시 검증 필요. 이용자데이터 수집은 범위명시. 이 인계만으로 공개서비스준비완료가 아니다.

## 납품 체크
소스·에셋·실행명령·개발용테스트세이브·밸런스변경표·테스트결과·화면캡처·known_issues.md. 코드가 미완료면 미완료 범위를 정확히 보고. 저장데이터 초기화는 사용자의 확인 없이 하지 않는다.
