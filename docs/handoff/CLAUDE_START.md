# Claude 제작 지시 — ASTERIA / NOCTURNE v3

## 목표
모바일 세로형 자동전투 방치 RPG를 실제 동작하는 MVP로 구현한다. 디자인 범위와 게임 구현 완료를 혼동하지 않는다. 사용자 지시·저장소 AGENTS.md를 먼저 확인하고, 사용자 변경 파일을 보존한다.

## 먼저 읽고 볼 것
1. README, spec/06_DESIGN_AUDIT, 07_BESTIARY, 08_UI_AND_EFFECTS.
2. spec/01_IMPLEMENTATION, 02_DESIGN, 04_CHARACTERS, 05_MOTION_REFERENCE, 03_QA.
3. design/review.html, catalog.html, combat.html, styleguide.html; art/asset_manifest.json.
4. tokens.json / balance_seed.json. 밸런스 데이터는 실험 시작값이며 합격표가 아니다.

## 최신 결정
- 매끄러운 성인 여성 일러스트. 도트/치비/픽셀 폰트/정수 확대를 재도입하지 않는다. MVP 세린28세, 동일한 얼굴·머리색·눈·장미 문장 유지.
- 첫 승급: 흑장미 기사(흰 금속/큰 방패) / 진홍의 집행자(검은 금속/양손 대검). 오래된 도끼 문구는 폐기.
- 390×844 기준, 360×700 대응. 전투 Canvas2D, UI DOM/SVG, Vanilla JS. 폰트 Noto Sans KR.
- 장비4부위·3등급, 강화+10 확정, 방치12시간·75% 실험값, 승급 대기 EXP 보관. 원안 수치와 중복 적용 금지.
- 장비 소환은 확장 시안. 실제 광고·결제·캐릭터 가챠·호감도 시스템을 추가하지 않는다.

## 에셋 연결
새 일반6/보스3/배경3/승급2/아이콘32는 art 폴더. 검토용 아틀라스 셀을 추출할 때 경계에 다른 개체/이펙트가 묻지 않는지 실제48px·전투 크기에서 확인한다. 원본 보드는 보존하고 변환 결과는 별도 runtime 폴더에 저장한다. alpha·trimOffset·pivot·hitbox·animation event를 메타데이터로 기록한다.

세린8포즈와 적1장 변형 시연은 타이밍 참고다. 연속 프레임을 만들거나 컷아웃 리깅을 제작해 접지/무기 궤적/얼굴 동일성을 검수한다. 불가능하면 known_issues에 구체적으로 적고 완성이라고 보고하지 않는다. 피해·궁극기 게이지·보상은 전투 이벤트에서 처리하고 프레임 수/영상 재생에 맡기지 않는다.

## 구현 순서
1. 상태 머신·저장 트랜잭션·한 전투·강화·복귀 정산 수직 단면.
2. 장비/잠금/분해/비교, 스킬, 보스, 패배 복귀, 인벤토리 초과.
3. 지역3, 던전, 승급2갈래, 신규 에셋과 실제 애니메이션.
4. 접근성·성능·저장 실패/복구/다중 탭·밸런스 측정.

정적 UI 버튼은 샘플이다. 22개 화면의 정상·오류 상태를 실제 상태와 연결하고, 부족한 골드/권한/조건에서 재화가 차감되지 않게 한다. 보상 저장 확정 전에 획득 연출을 시작하지 않는다. 초기화/가져오기 덮어쓰기는 사용자에게 결과를 설명하고 확인받는다.

## 납품 조건
실행 코드, 실행 방법, 적용 에셋/원본, 검수 결과,390×844/360×700 화면, known_issues, 밸런스 변경표를 납품한다. 설계/구현/검증을 각각 구분한다. 로컬 저장의 치트/기기 이동 한계를 명시한다. 공개 배포·원격 push는 별도 지시 없이 하지 않는다.
