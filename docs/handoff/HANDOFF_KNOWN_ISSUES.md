# 남은 제작 목록

이 패키지에서 완료된 것은 MVP 디자인 검토와 원화/시안/모션 참고의 보강입니다.

- P1: 세린과 승급 복장2종, 일반 적6종·보스3종의 연속 애니메이션 또는 컷아웃 리깅.
- P1: 생성 보드의 개체별 가장자리 정리 및 runtime atlas 패킹. 현재 JSON은 검토용 영역입니다.
- P1: 실제 전투/저장/보상/장비/승급 로직과 22개 UI 상태 연결.
- P2: 메인 그림의 일부 전투 포즈에서 검·장식 형태의 미세한 일관성 보정.
- P2: 폰트 WOFF2 서브셋·이미지 리사이즈 캐시·지역별 lazy loading.
- P2: UI 전체 키보드/스크린리더/실제 모바일 검수.
- P3: 확장4클래스 전투 시트, Lv60/90 승급, 추가7지역과 지역보스7종, 최종 레이드.
- P3: BGM·최종 효과음·보이스. 동봉 WAV는 모션 시연용 합성 효과음입니다.

새로운 그림/영상이 존재한다는 이유만으로 해당 게임 시스템까지 완성이라고 판정하지 않습니다.
