# 구현 명세 v2.0

## 0. 요구사항 우선순위
이 문서의 MUST는 1단계 MVP 필수, SHOULD는 시간이 허용되면 구현, LATER는 확장 전용이다. 최초 사용자가 제시한 최종 비전은 유지하되 아래 변경안으로 위험을 줄인다. 실제 사용자에게 새 요구가 오면 이를 우선한다.

## 1. 핵심 경험
자동 전투 → 보상 → 선택적 성장 → 보스 도전 → 새 지역 → 첫 승급 → 복귀 보상. 접속 때마다 1~3개의 의미 있는 행동을 할 수 있어야 한다. 이동 조작은 없고 스킬 수동 시전은 선택이다. 장비·스킬 조합으로 일반 사냥과 보스 성능이 달라져야 한다.

## 2. 스코프와 콘텐츠 연결
MUST: 지역1 별빛 초원(Lv1~10), 지역2 고대 사막(Lv11~20), 지역3 잊힌 폐광(Lv21~35). 지역마다 웨이브10, 웨이브별 일정 처치 후 진행, 마지막 보스. 사냥터 레벨과 플레이어 레벨은 별개이며 권장 레벨은 잠금 조건이 아니다. 기본 waveKillTarget=10, 시뮬레이션 후 조정.
보스3: 가시 슬라임(기본 공격 읽기), 모래 수호자(주기적 강공), 폐광 파수꾼(방어 타이밍). 보스 도전은 무료. 실패하면 직전 검증 사냥 위치로 자동 복귀한다. 성공하면 새 지역/파밍 위치를 연다. 보스 제한시간90초, 적정 빌드 목표30~60초.
재료 던전1: 하루3회, 최대9회 누적, 최고 클리어 단계 소탕 가능. MVP 클라이언트 리셋 기준은 Asia/Seoul 00:00으로 명시한다. 임의 로컬 시간 조작 완전 방어는 주장하지 않는다. 입장 시 소비하며 크래시한 미완료 전투는 저장된 진입 트랜잭션을 복구해 이어가거나 1회 환급한다. 종료 결과를 두 번 지급하지 않는다.
LATER: Lv100, 사냥터10, 지역 보스10, 던전 종류 확장, 주간 레이드, 무한 탑, Lv91 최종 심연. '던전10곳'은 10종인지 난도인지 미정이므로 MVP에서 임의로 구현하지 않는다.

## 3. 전투 규칙
상태: BOOT → LOAD → FARM ↔ BOSS; DEFEAT → FARM; DUNGEON → RESULT → FARM; PROMOTION_TRIAL → RESULT → FARM. UI 탭 전환은 전투 상태를 바꾸지 않는다. 탭 숨김은 시뮬레이션을 중단하고 복귀 정산한다.
- 고정 논리 tick 50ms. 렌더는 requestAnimationFrame, 낮은 FPS에서도 동일한 시간당 피해.
- 일반 공격은 공격속도에 따라 발생. 타격 판정은 action/event 기준. 다단히트 한 번의 행동을 여러 충전 행동으로 세지 않는다.
- 피해: max(1, floor(ATK * coefficient * K/(K+DEF) * critMultiplier * random(0.9,1.1))). MVP K=50+10*enemyLevel 초기값. 플레이어/적에 동일 규칙 적용.
- 치명 확률 초기5%, 상한60%; 치명 피해 초기150%. 공격속도 초기1.0/s, 상한3.0/s. 상한 도달 강화 버튼은 비용을 받지 않는다.
- 일반 공격 행동 완료 시 궁극기+2, 실제 피격 행동당+1(초당최대2), 처치+5. 게이지0~100 클램프. 광역 다중처치는 한 행동당 처치충전 최대10.
- 궁극기 사용 시100 소모. 자동 옵션 OFF / ELITE_BOSS / ALWAYS. 수동 시전은 조건 충족 시 우선.
- ×2는 전경 시뮬레이션 진행 속도2배. 쿨타임·적 공격·스폰도 함께2배. 방치 기준 수익은 ×1 기준이며 ×2·광고·일시 버프 제외. 이를 UI 도움말에 명시한다.
- HP 0이면 실패. FARM은3초 뒤 전투 재개, 보스·던전은 결과 후 사냥 복귀. 골드·장비 손실 없음.

## 4. 성장과 초기값
balance_seed.json은 시작점이며 밸런스 합격표가 아니다. 원안 EXP=floor(100*Lv^1.8)은 유지하되 실제 레벨업 시간은 몬스터 EXP 보상과 함께 조정한다. Lv35 이후 MAX, 이후 EXP는 MVP 확장 적립 없음으로 안내한다. 승급 잠금의 EXP 보관과 만렙은 다르다.
플레이어 초기: ATK20, HP200, DEF10. 레벨업 기본 증가 ATK+3, HP+25, DEF+1. 골드 강화 5종: ATK+2, HP+20, DEF+1, CRIT+0.2%p, ASPD+0.01/s. 비용 각각 base*[1.15^해당강화횟수] 올림. base=10/10/12/30/30. 레벨 스탯·강화·장비 보너스 합성 순서를 하나의 함수로 관리.
몬스터 원안 HP50*1.12^Lv, ATK8*1.10^Lv는 보존한 참고값이며 MVP 후반 시뮬레이션에서 반드시 보정한다. 초반 적 DEF=0, 초반 일반 공격 간격1.8초. 정예 HP×3·ATK×1.3, 보스 HP×40·ATK×2. 스테이지마다 출현 수·스폰 대기를 정의해 시간당 수익 계산.
강화 ×1/×10/×100/MAX는 한 번에 구매 가능한 횟수와 총비용을 계산한다. ×10을10회 살 수 없으면 가능한 수량을 표시하고 그만큼만 구매. MAX가0이면 부족액 표시. 표기 반올림 때문에 구매 가능 여부를 판정하지 않는다.
측정 목표: 첫 강화30~60초 이내, 첫 장비3분 이내, 첫 보스첫10분 안, 일반 적2~4초, 적정 보스30~60초. 목표 미달이면 수입·비용·스폰·체력을 함께 조정하고 기록한다. 첫 승급은 첫주 안 목표이며 프로토타입 QA에는 개발용 가속 세이브를 별도 제공한다.

## 5. 장비와 인벤토리
MUST 4부위: 무기·투구·갑옷·장신구. 일반/고급/희귀 배율1/1.25/1.6. 장비 레벨 기준 기본값과 부위별 주 스탯을 데이터화한다. 무기는 ATK, 투구·갑옷은 HP/DEF, 장신구는 ATK 또는 CRIT. 상한 넘는 옵션은 실효값에 반영하지 않는다.
매 처치 장비 발생 확률5%; 발생했을 때 일반70%/고급25%/희귀5%. 원안4등급 드롭표를 그대로 겹쳐 쓰지 않는다. 정예·보스는 별도 테이블. 첫 보스는 희귀 무기1개 확정, 첫 지역 보상은1회만. 아이템ID별 수령 플래그 저장.
강화 +0~+10 확정. 1단계당 기본 주 스탯 +5% 합연산. 재료 비용 floor(5*1.5^현재강화). 장비 교체 자체에는 비용 없음. 분해 시 일반1/고급3/희귀8 재료+투입 강화재료80% 내림 환급. 장착/잠금 아이템 일괄 분해 금지. 분해 전 개수와 재료 합계 확인.
자동 장착은 부위별 예상 전투 성능 평가. 최소 MVP에서는 '주 스탯 기준'이라고 명확히 표기하고 실제 DPS 최적이라고 주장하지 않는다. 잠금·필터·일괄분해 필수. 인벤토리200칸, 초과 장비는 임시 보관함으로 보내며 자동 삭제하지 않는다. 방치 정산은 장비를 최대20개까지 생성, 초과 발생분은 명시된 일반 등급 재료로 전환하고 내역 표시.
LATER 8부위·6등급·랜덤옵션·세트·신화. 새 장비로 교체할 때 기존 성장 투자가 무의미해지지 않게 강화 이전/환급 유지.

## 6. 스킬과 승급
기본 일반스킬3+궁극기1. 승급마다 일반스킬1개 추가. 최종 일반6 중4개 장착+궁극기 별도1칸. MVP 1차 후 일반4+궁극기1. 기본3개일 때 네 번째 슬롯은 '승급 해금'.
초기 일반: 강타(계수2.0/CD6s), 방패 돌진(1.5/CD8s, 방어효과), 전장의 외침(8초 ATK+20%, CD20s). 궁극기 별빛 참격(6.0). 버프 중첩은 같은 종류 최대값, 재사용 시 지속시간 갱신. 자세한 피해/방어 버프는 데이터에서 지정.
스킬 레벨1~10, 피해성 스킬은 1+0.08*(레벨-1) 합연산. MVP 스킬 레벨은 플레이어 레벨·승급에 따른 자동 해금, 스킬북 구매 없음. 비피해 스킬은 별도 효과 테이블 사용.
1차 승급 Lv30: 증표20개+폐광 보스1회 클리어+교관 시련. Lv25부터 증표 진행. 적격 적5마리 처치마다 증표1개 확정, 진행 UI에 남은 수량 표시. 재료는 성공 확정 시 소비. 시련 실패 재료·입장권 미소모, 자동 모드와 수동 스킬 개입 모두 가능.
Lv30 잠금에서 새 EXP는 pendingExp에 보관. 승급 완료 후 정상 필요 EXP에 순차 적용. 만렙35까지만 적용하고 초과는 MVP MAX 규칙에 따라 안내. XP는 보상 때마다 한 번만 적용한다.
나이트: 큰 방패 실루엣, 신규 수호 반격. 방패 돌진 방어 시간 안 받은 피해에 반응, 반격 내부CD1초.
버서커: 양손 대검 실루엣, 신규 광폭 일격. HP50% 이하에서 공격 보너스, 과도한 생존 손해 없도록 측정.
분기 선택 전 설명과 외형 비교. 최초1회 전환 무료, 재전환은 MVP 개발설정에서만 허용하고 후속 상품화 금지. 전환 시 레벨/장비/퀘스트 유지, 분기 전용 스킬만 교체.
LATER Lv60/90 승급, 고정+40/+60 대신 작동 방식·비율 효과 중심. 모든 클래스 왕관 규칙 없음.

## 7. 방치 정산·저장
파밍 검증: 같은 웨이브에서 연속3회 처치 주기를 생존 완료하면 해당 웨이브를 후보로 저장. 시간당 수익은 데이터 기반 ×1 시뮬레이션 값 또는 최소60초 안정 구간 측정값 사용, 방식과 버전 명시. 전투력 수치만으로 마지막 보스 수익을 지급하지 않는다.
보상 = floor(검증 수익률 * min(경과초,43200) *0.75). EXP·골드·기본 재료·희귀이하 장비만. 포션/입장권/승급 증표/보석 지급 없음. 오프라인 보상으로 스테이지 자동 클리어 없음.
MVP 로컬 저장: IndexedDB 우선, 실패 시 명시적 오류와 내보내기 안내. localStorage는 설정·작은 저장의 fallback 가능. local-only 데이터 조작 허용 한계 명시. 슬롯 current/previousGood, schemaVersion, balanceVersion, savedAt, lastClaimId, lastClaimAt. 주요 지급·소모를 원자적 단위로 저장.
세이브 최소 항목: player(level,exp,pendingExp,branch,statsUpgrades), wallet, inventory, equipped, skills, progression, dungeonTickets, promotion, offlineSnapshot, transactions, settings. 동일 보상 transactionId 중복 처리 금지. 획득 연출 전에 저장 확정. 슬롯이 손상되면 이전 정상본 복구 여부 안내.
visibilitychange(hidden)·중요 보상/소비 직후 저장. 전경 중20초마다 체크포인트. 종료 이벤트만 의존하지 않는다. 숨김 이후 복귀 시 오프라인 정산하고 전경 시뮬레이션 누적 dt를 다시 돌리지 않는다. 여러 탭은 한 탭만 쓰기 가능하게 잠금/세이브 revision 충돌 감지.
경과시간 음수는0, 비정상 미래값은 상한으로 제한하고 진단 기록. 서버 없이 시계 조작 완전 방지 불가. 계정/결제/랭킹 확장 전 서버 authoritative 재화·시간·소환·입장·중복 방지 구현.

## 8. 수익화와 확장 정책
MVP 실제 광고·결제 없음. 디자인의 광고 버튼은 '후속 시안', 소환은 '확장' 표기. 사용자 테스트에서 실제 광고를 재생하는 듯 가짜 보상 지급하지 않는다.
확장 소환: 기존52/30/14/3.5/0.49/0.01%는 과거 참고값으로만 보존. 최종 확률은 보석 수급·천장·목표 획득 일수와 같이 결정. UI 시안의 전설 천장200은 실험안, 서버 상품 설정 확정값 아님. 신화는 레이드 확정 제작 경로 제공. 자동소환 예산 상한·횟수·전설이상 정지·11회묶음 단위 처리 명시.
