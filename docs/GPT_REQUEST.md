## 공통 조건 (모든 요청 맨 앞에 붙이기)

```
[아스테리아 공통 아트 조건]
- 화풍: 지금까지 준 세린·엘레나·리라·녹스 원화와 같은 비도트 다크 판타지 반실사 일러스트. 픽셀아트·치비·SD 금지.
- 캐릭터는 모두 성인(세린 28, 엘레나 30, 리라 26, 녹스 29). 기존보다 노출을 늘리지 않음.
- 배경: 투명 PNG(알파). 안 되면 아주 어두운 단색(#1c1726) 평면. 그라데이션·빛 번짐(헤일로)·바닥 그림자·바닥면 금지.
  (빛 번짐이 있으면 잘라낼 때 가장자리가 지저분해집니다. 마법 빛·불꽃 같은 효과는 개체에 붙은 것만 그려 주세요.)
- 판 크기: 1536×1024 (또는 2048×1365 같은 3:2). 칸은 같은 크기 격자로 나누고, 개체가 칸 밖으로 나가거나 옆 칸과 겹치지 않게.
- 전신·끝까지: 발끝, 무기 끝, 날개·꼬리 끝이 칸 안에 다 들어오게. 칸마다 위아래·좌우 여백 8% 이상.
- 방향: 아군(주인공·동료)은 오른쪽을 봄. 적(몬스터·보스)은 왼쪽을 봄.
- 한 판 안에서는 크기(키)와 발 위치(바닥 기준선)가 같게.
- 글자·숫자·테두리·워터마크 없음.
```
