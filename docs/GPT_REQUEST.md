# GPT 디자인 요청서 (아스테리아 연대기 · NOCTURNE)

게임에 바로 넣을 수 있도록 형식을 맞춘 요청서입니다. **공통 조건**을 먼저 붙이고, 필요한 묶음(B~I)을 하나씩 요청하세요.
**적용 완료: A(승급 포즈 24종, A01·A02) · B(투사체·타격 효과) · I(스테이지 지도 10장) · C(몬스터 20종 4동작) · D(보스 11종 4동작) · E(동료 6종 3동작) · F(아이콘 41개) · G(배경 4장).** 남은 것: H(세린 찌르기 보정). 받은 PNG는 파일 이름을 아래 표대로 붙여 대화에 올려 주면 됩니다.

---

## 공통 조건 (모든 요청 맨 앞에 붙이기)

```
[아스테리아 공통 아트 조건]
- 화풍: 지금까지 준 세린·엘레나·리라·녹스 원화와 같은 비도트 다크 판타지 반실사 일러스트. 픽셀아트·치비·SD 금지.
- 캐릭터는 모두 성인(세린 28, 엘레나 30, 리라 26, 녹스 29). 기존보다 노출을 늘리지 않음.
- 배경: 투명 PNG(알파). 안 되면 아주 어두운 단색(#1c1726) 평면. 그라데이션·빛 번짐(헤일로)·바닥 그림자·바닥면 금지.
  (빛 번짐이 있으면 잘라낼 때 가장자리가 지저분해집니다. 마법 빛·불꽃 같은 효과는 개체에 붙은 것만 그려 주세요.)
- 판 크기: 1536×1024 (또는 2048×1365 같은 3:2). 칸은 같은 크기 격자로 나누고, 개체가 칸 밖으로 나가거나 옆 칸과 겹치지 않게.
- 전신·끝까지: 발끝, 무기 끝, 날개·꼬리 끝이 칸 안에 다 들어오게. 칸마다 위아래·좌우 여백 8% 이상.
- 방향: 아군(주인공·동료)은 오른쪽을 봄. 적(몬스터·보스)은 왼쪽을 봄.
- 한 판 안에서는 크기(키)와 발 위치(바닥 기준선)가 같게.
- 글자·숫자·테두리·워터마크 없음.
```

## B. 투사체·타격 효과 — ✅ 완료 (assets/source/gpt_b, tools/extract_gpt_b.py)

원거리 공격이 지금은 코드로 그린 빛줄기라 그림으로 바꾸려 합니다.

```
[B. 투사체·이펙트 시트] fx_projectiles.png
- 판: 1536×1024, 4열×3행, 12칸. 배경 투명. 모든 투사체는 오른쪽으로 날아가는 방향.
- 1행: 엘레나 성광탄(별 모양 마법탄+꼬리), 엘레나 심연탄(녹색), 리라 화살(깃털 달린 화살), 리라 빛나는 화살(스킬용)
- 2행: 녹스 던지는 단검, 녹스 카드, 메테오(큰 불타는 별), 화살비 화살 묶음(아래로 떨어짐)
- 3행: 타격 불꽃(흰·금), 마법 타격(보라), 독 타격(녹색), 치명타 섬광(금빛 별)
```


## I. 스테이지 지도 — ✅ 완료 (assets/source/gpt_i, tools/extract_gpt_i.py · 길은 그림에 맞춰 노드 위치를 따로 잡음)

지금 스테이지 지도는 전투 배경(가로 그림)을 세로로 잘라 깔고, 길·노드를 코드로 그립니다. 지역마다 **세로 지도 그림**을 받으면 그 위에 노드를 코드로 올립니다.

```
[I. 스테이지 지도] (지역 1곳당 1장)
- 판: 1024×1536 세로(2:3). 배경 투명 아님(꽉 찬 그림).
- 위에서 내려다본 손그림 판타지 지도 느낌 + 그 지역 풍경(같은 화풍).
- 아래쪽 가운데 근처에서 시작해 좌우로 굽이치며 위로 올라가는 길 1개(흙길·돌다리·눈길 등 지역에 맞게).
  길은 아래 좌표(가로 %, 세로 %)를 차례로 지나가게: (15,85) (39,80) (63,84) (85,72) (63,62) (37,60) (15,49) (32,37) (58,36) (83,27) → 꼭대기 (60,12) 보스 자리.
- 노드·숫자·글자·아이콘은 그리지 말 것(코드가 올림). 좌표 자리는 지름 6% 정도 평평하게 비워 두기.
- 꼭대기 (60,12) 주변은 보스 둥지(성문·제단·동굴 입구 등). 왼쪽 위 (0~40%, 0~10%)는 제목 상자가 올라가니 복잡하지 않게.
- 전체를 약간 어둡게(글자 대비), 가장자리 비네트.
```

| 파일 이름 | 지역 | 길·분위기 |
|---|---|---|
| map_meadow.png | 1 별빛 초원 | 들꽃 사이 흙길, 폐허 정원, 꼭대기 슬라임 둥지 |
| map_desert.png | 2 고대 사막 | 모래 언덕 사이 돌길, 피라미드, 꼭대기 신전 문 |
| map_mine.png | 3 잊힌 폐광 | 레일·나무 다리, 수정 광맥, 꼭대기 갱도 입구 |
| map_forest.png | 4 어둠의 숲 | 뿌리 사이 오솔길, 거미줄, 꼭대기 거미 둥지 |
| map_glacier.png | 5 얼음 산맥 | 눈길·얼음 다리, 오로라, 꼭대기 얼음 동굴 |
| map_volcano.png | 6 화산 지대 | 용암 사이 현무암 길, 꼭대기 화구 제단 |

### 그림이 아닌 것 (GPT 요청 대상 아님)
- 배경음악·효과음: 지금은 코드로 만든 임시음입니다. 원하면 음원 소스(무료 라이선스) 쪽으로 따로 찾아볼게요.
- 실기기 확인(아이폰 Safari·안드로이드 Chrome): 선배 폰에서 직접 봐 주셔야 합니다. 이상한 화면은 캡처해서 올려 주세요.
- 서버 기능(계정·랭킹): 그림이 아니라 서버(예: Firebase)가 필요합니다.
