# v5 1부 — 특성 · 환생 · 균열

선배가 고른 신규 콘텐츠 중 앞쪽 절반입니다. 펫·도감·업적·시즌 패스·신화 제작은 다음 작업에서 합니다.
모든 변경은 `Game.transact`를 거칩니다(실패한 저장은 아무것도 주지 않음). 저장 스키마 3 → 4.

## 1. 특성 (`src/data/talents.js`, `src/core/talents.js`, 메뉴 → 특성)
- **열림**: 1차 승급(Lv 30) 후.
- **포인트**: (최고 레벨 − 30, Lv 31부터 레벨당 1), 탑 10층마다 +1, 환생 1회마다 +3. `player.peakLevel` 기준이라 환생해도 포인트가 줄지 않습니다.
- **트리**: 클래스마다 3개입니다. 갈래 트리 2개는 둘 다 찍을 수 있고, 공용 트리(생존·재화) 1개가 더 있습니다.
  - 각 트리는 5줄입니다. 1–4줄은 노드 2개(랭크 1–5), 5줄은 핵심 특성 1개(랭크 1)입니다.
  - 줄 N을 찍으려면 같은 트리 윗줄에 5×(N−1)포인트가 필요합니다.
- **핵심 특성** (전투에 실제로 구현):
  | 트리 | 핵심 특성 | 효과 |
  |---|---|---|
  | 기사 | 이중 반격 | 반격 ×2 (0.5초 내부 대기), 반격 스킬이 없으면 방어 +1초 |
  | 광전사 | 피의 군주 | 저체력일 때 공격력 +50%, 흡혈 3% |
  | 위자드 | 이중 유성 | 궁극기가 60% 위력으로 한 번 더 떨어짐 |
  | 워락 | 역병 | 지속 피해 ×2 |
  | 레인저 | 추적 화살비 | 화살비 타수 ×1.5 |
  | 헌터 | 우두머리 | 야수 계수 ×2, 2% 회복 |
  | 어쌔신 | 그림자 일격 | 그림자 걸음 후 3타 확정 치명 |
  | 트릭스터 | 환영 무도 | 25% 확률로 추가 1타 |
  | 공용 | 재기 | 전투당 1회, 죽을 피해를 맞아도 HP 30%로 생존 |
- **프리셋**: 2개(사냥용/보스용). "전투 입장 시 보스용 자동 전환"을 켜면 보스·시련·던전·탑·레이드·균열은 프리셋 2를, 사냥은 프리셋 1을 씁니다.
- **초기화**: KST 하루 1회 무료, 그 뒤로는 골드(현재 사냥 30분치)가 듭니다. 확인 창에서 비용을 알려줍니다.
- **자동 분배**: 기본은 꺼짐입니다. 켜면 자기 갈래 → 공용 → 다른 갈래 순으로 찍고, 자기 갈래 핵심 특성을 가장 먼저 노립니다.

## 2. 환생 (`src/core/rebirth.js`, 메뉴 → 환생)
- **조건**: Lv 100. 'B10 첫 처치'가 아니라 레벨로 정했습니다. 레벨은 모든 클래스가 같은 기준으로 도달하고 보스 상성을 타지 않기 때문입니다.
- **초기화되는 것**: 레벨(→1), 경험치·보관 경험치, 골드, 골드 자동 강화 단계, 능력치 포인트(자동 재분배), 사냥 위치(별빛 초원 W1).
- **남는 것**:
  - 클래스, 승급 단계·갈래. 이미 받은 승급의 레벨 잠금은 다시 걸리지 않습니다.
  - 장비, 가방, 보석·뽑기권·재료.
  - 스킬·스킬북·각인·특성.
  - 지역 개방, 보스·탑·레이드·균열 기록.
- **환생 정수**: 기본 30 + 탑 최고층 × 0.5 + 환생 횟수 × 5.
- **영구 강화**: 공격력·최대 HP는 단계당 ×0.08(비용 10·1.35^단계), 골드·경험치는 단계당 ×0.10(비용 8·1.3^단계). 최대 50단계입니다.
- **기억의 가속**: 이전 최고 레벨에 닿을 때까지 경험치 ×8. 사냥과 방치 모두에 적용됩니다.
- **자동 재등반**: 환생 후에는 보스를 이미 잡은 지역의 W10에 닿으면 다음 지역 W1로 자동 이동합니다. 다음 지역 시작 레벨이 영웅 레벨 +5 이하일 때만 이동합니다.
- **확인**: 환생 화면에 초기화되는 것과 남는 것을 모두 적고, 빨간 확인 창을 한 번 더 띄웁니다(선배 규칙: 초기화는 설명 + 확인). 사냥 중일 때만 할 수 있습니다.
- **목표 루프**: 환생 1회가 약 1일. 시뮬 결과는 아래 BALANCE_CHANGES에 있습니다.

## 3. 균열 (`src/core/rift.js`, 모험 → 균열)
- **열림**: 사막 보스(B03) 처치 후. KST 하루 무료 2회.
- **층 구성**: 처치 목표 8마리, 제한 45초.
  - 적 레벨은 내 레벨 −3에서 시작해 층마다 +1, 능력치는 층마다 +10%입니다. 5층마다 정예 러시입니다.
  - HP는 다음 층으로 이어지고, 층을 깰 때 30%를 회복합니다.
  - 최대 30층입니다. 30층을 깨면 완주로 처리하고 보상을 줍니다. 한 판이 끝없이 이어지지 않게 하려는 장치입니다.
- **축복**: 층을 깰 때마다 20종 중 3개를 보여주고 1개를 고릅니다(일반 60 / 희귀 30 / 영웅 10). 같은 판·같은 층이면 언제나 같은 3개가 나옵니다. 축복은 그 판의 균열 전투에서만 적용됩니다.
- **주간 저주**: KST 월요일마다 6종 중 하나로 바뀝니다(분노·강철·서두름·기근·유리·암흑).
- **판 종료**: 사망, 시간 초과, "보상 받고 마치기", 30층 완주.
- **보상**: 깬 층 수에 비례합니다. 층당 보석 8·광석 10·골드 1분치, 2층마다 스킬북 1, 10층마다 환생 정수 1. 탐욕 축복은 보상 +25%입니다.
  - `markTx(runId:end)`로 한 판에 한 번만 지급합니다.
  - 최고 층 기록이 남습니다.
- **이어하기**: 판 상태가 `state.rift.run`에 저장됩니다. 다시 열면 현재 층 처음부터 이어 하거나, 고르지 않은 축복 선택으로 돌아갑니다.
- **기획과 달라진 점**:
  - '균열 유물'은 별도 아이템으로 만들지 않았습니다. 보상은 보석·광석·골드·스킬북·환생 정수로 단순화했습니다.
  - '추가 투사체' 축복 대신 추가타 확률 축복(연격·메아리)을 넣었습니다. 지금 전투에는 투사체 개념이 없습니다.

## 4. 아이콘 자리표시
`src/ui/v5.js`의 `V5_ICONS`와 `src/data/talents.js`의 `TALENT_ICONS`는 id별로 기존 아이콘을 임시로 씁니다(특성 K30, 환생 S5, 균열 K35, 트리별 임시 아이콘). 아이콘 보드가 오면 이 두 맵만 바꾸면 됩니다.
