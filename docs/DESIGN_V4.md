# v4 확장 설계 (기획서 전체 + 뽑기)

출처: "HTML RPG 게임 기획서"(첫 기획서) + v3 인계 + 선배 추가 요청(게스트 로그인, 출석·복귀, 뽑기).
충돌 시: v3의 안전 규칙(실결제·광고·캐릭터 가챠·호감도 없음, 성인 캐릭터, 저장 트랜잭션)이 우선. 수치는 모두 실험값.

## 1. 클래스 (4) — 새 게임 시작 시 선택, 기존 저장은 전사
| id | 이름 | 주인공 | 역할 | 사거리 | 기본 보정 |
|---|---|---|---|---|---|
| warrior | 전사 | 세린(28) | 근접 탱커/딜러 | melee | hp ×1.25, def ×1.3 |
| mage | 마법사 | 엘레나(30) | 원거리 광역 | ranged | atk ×1.15, hp ×0.85, 광역 스킬 |
| archer | 궁수 | 리라(26) | 원거리 단일 | ranged | atk ×1.1, crit +5%, aspd +10% |
| rogue | 도적 | 녹스(29) | 근접 치명·회피 | melee | crit +10%, 회피 8%, hp ×0.95 |

스킬(기획서 6.1): 클래스당 스킬 3 + 궁극기 1. id 접두어로 클래스 구분.
- 전사: w_strike 강타(단일 1.8, cd 3) / w_whirl 회전베기(전체 1.2, cd 6) / w_cry 전투의 함성(방어 +30% 8초, cd 20) / 궁 w_ult 대지 분쇄(전체 6.0 + 기절 2초)
- 마법사: m_fireball(단일 2.0, cd 2) / m_frost 서리 고리(전체 1.4 + 둔화, cd 8) / m_shield 마나 실드(피해 흡수 = 최대HP 25%, 10초, cd 25) / 궁 m_ult 메테오(전체 3.5 ×3)
- 궁수: a_aim 정조준(단일 2.2, cd 3) / a_multi 멀티샷(전체 0.8 ×5분배, cd 5) / a_leap 후방 도약(2초 회피 100%, cd 10) / 궁 a_ult 화살비(전체 1.5/초 5초)
- 도적: r_stab 급소 찌르기(단일 1.6, 치명 +30%, cd 2) / r_poison 독칼(단일 지속 0.5/초 6초, cd 7) / r_shadow 그림자 걸음(은신 2초 = 회피 100% + 다음 공격 치명, cd 15) / 궁 r_ult 천 개의 칼날(단일 0.9 ×12)

기존 세린 v3 스킬(strike/shieldCharge/warCry/starSlash/guardCounter/berserkStrike)은 전사에 그대로 유지(호환). 전사 기본 = strike, shieldCharge, warCry, 궁 starSlash. 위 w_* 표는 참고용으로만 두고, 전사는 기존 id를 쓴다(회전베기는 2차 승급 스킬로 편입).

## 4. 장비 — 6등급 · 8부위 · 옵션 · 세트 · +15
- 등급: common 일반 I(회색) / uncommon 고급 II(초록) / rare 희귀 III(파랑) / epic 영웅 IV(보라) / legendary 전설 V(주황) / mythic 신화 VI(빨강)
- 배율 1.0 / 1.2 / 1.5 / 1.9 / 2.5 / 3.2, 랜덤 옵션 0/1/2/3/4/4+고유
- 부위: weapon, helmet, armor, gloves, boots, necklace, ring ×2(ring1, ring2 장착칸, 아이템 slot='ring')
- 옵션 풀: atkPct, critChance, critDmg, aspd, hpPct, defPct, cdr, ultCharge, goldPct. (이동 속도는 자동 전투에 의미 없어 제외)
- 신화 고유: mythUltCdr(궁극기 후 5초 스킬 쿨 50% 감소), mythHeal(처치 시 10% 확률 HP 20% 회복)
- 드롭(일반 몬스터): 70/25/4.5/0.5/0/0, 정예는 한 단계 위 표 사용, 보스: 고급 확정 1 + 희귀 60% / 영웅 30% / 전설 9.5% / 신화 0.5%(Lv91+ 레이드만)
- 세트: 보스 드롭 방어구(helmet/armor/gloves/boots)는 그 지역 세트. 2세트 / 4세트 보너스(지역별 표).
- 강화 +0~+15: +1~5 100%, +6~10 70→30%(선형), +11~15 20→5%. 실패: +10 이하 유지, +11 이상 1단계 하락. 파괴 없음. 단계당 기본 능력치 +5%. 비용: 강화 광석.
- 분해: 일반 1 / 고급 3 / 희귀 8 / 영웅 20 / 전설 60 / 신화 200 광석 + 투입 광석 80%.
- 자동 분해 설정: 끔 / 일반 / 고급 이하 / 희귀 이하 (잠금·장착 제외, 새로 얻은 장비에만).

## 5. 뽑기 (게임 내 재화만, 확률 공개, 천장)
### 장비 뽑기 (별의 유산)
- 1회 보석 50 또는 장비 뽑기권 1, 11회 보석 500 또는 뽑기권 11(뽑기권 우선 사용)
- 확률(소환 Lv1): 일반 52 / 고급 30 / 희귀 14 / 영웅 3.5 / 전설 0.49 / 신화 0.01 (%)
- 소환 레벨 1–10: 누적 뽑기 수로 상승(10/40/100/200/350/550/800/1100/1500), 레벨마다 상위 등급 확률 증가(표 공개)
- 천장: 전설 이상 미획득 200회째 전설 확정(카운터 표시, 전설 이상이 나오면 0)
- 장비 레벨 = 현재 플레이어 레벨, 부위 무작위
### 스킬 뽑기 (스킬 서고)
- 1회 보석 80 / 스킬 뽑기권 1, 11회 800 / 11장
- 결과: 스킬북(내 클래스 스킬 하나, 일반 3권 / 희귀 8권 / 영웅 20권) 또는 고유 각인(전설)
- 확률: 스킬북 일반 70 / 희귀 22 / 영웅 7 / 각인 전설 1 (%), 천장 100회째 각인 확정
- 고유 각인 8종(모든 클래스 공용 패시브, 각인 슬롯 2): 흡혈(피해 3% 회복), 연격(10% 확률 추가타 50%), 별의 가호(받는 피해 -8%), 황금손(골드 +15%), 집중(치명 피해 +25%), 질풍(공속 +10%), 철벽(최대 HP +12%), 충전(궁극기 충전 +20%). 중복 획득 = 각인 레벨 +1(최대 5, 효과 +20%/레벨)
- 실결제·광고 없음. 보석 공급: 출석, 복귀, 일일 미션, 보스 최초 처치, 탑 층 보상, 레이드, 필드 보스.

## 6. 스킬 레벨 1–10
- 스킬북 + 골드로 레벨업. 필요 스킬북 = 레벨 n→n+1: 2n, 골드 = goldPerMinute(플레이어 Lv) × 3n
- 레벨당 피해 +8%(기존 규칙). 스킬북 출처: 스킬 뽑기, 스킬북 서고 던전, 보스.

## 7. 던전 3종 + 시련의 탑 + 주간 레이드
- 별의 채석장(강화 광석, 기존), 황금 금고(골드), 스킬북 서고(스킬북). 각 입장권 일 3 / 최대 9, KST 00:00. 소탕 = 최고 단계.
  - 금고: 60초 동안 황금 골렘 처치 수 비례 골드. 서고: 단계 클리어 시 스킬북 3+단계/3.
  - 열림: 금고 = B02 처치, 서고 = B03 처치.
- 시련의 탑: 입장권 없음, 층마다 60초 안에 웨이브 처치(층 = 적 Lv 5 + 층×2, 정예 비율 상승). 층 보상: 보석 10, 5층마다 보석 50 + 각성석 2, 10층마다 별의 파편 1(30층부터). 2차 승급 조건 5층.
- 주간 레이드 "심연의 문": Lv 91+ & B09 처치 후. 주 3회(월요일 00:00 KST 초기화), 120초 동안 심연의 군주에게 준 피해로 등급(D/C/B/A/S) 보상. S: 신화 0.5%·전설 확정 장비 + 별의 파편 2 + 보석 300.

## 8. 능력치 포인트 (기획서 2)
- 레벨업마다 5포인트. STR/INT/DEX → 클래스 주 스탯이면 공격 +2(아니면 +0.5), VIT → HP +15·방어 +1, AGI → 공속 +0.3%·회피 +0.2%·치명 +0.1%, WIS → 스킬 쿨 감소 +0.1%(최대 30%) (MP는 자동 전투에 맞지 않아 쿨 감소로 대체)
- 자동 분배(기본 켬): 클래스 추천 비율. 수동 분배 화면, 초기화는 골드 비용.
- 기존 골드 성장 강화는 유지(핵심 루프).

## 9. 일일 미션 (뽑기 재화 공급)
5개/일, KST 00:00 초기화: 몬스터 300처치, 강화 5회, 던전 1회, 뽑기 1회, 보스 1회 도전. 각 보석 20, 5개 모두 완료 시 보석 50 + 장비 뽑기권 1.

## 10. 기획서에서 의도적으로 바꾸거나 뺀 것
- 광고 무료 소환, 실결제: 없음(v3).
- 포션·MP·마을 귀환: 자동 전투 방치형에서 의미가 작아 제외(사망 시 3초 후 재개 유지).
- 오프라인 보상: v3 규칙(12시간·75%) 유지(기획서 8시간·50%보다 v3가 나중 결정).
- 사냥 범위·이동 속도 옵션: 횡스크롤 고정 전투라 제외.
- 사망 페널티(EXP 5%): v3 "손실 없음" 유지.
- 장비 슬롯 40칸 가방: v3 200칸 + 임시 보관 100 유지.
- 몬스터 리젠 8초: v3 리듬(0.9초) 유지.
