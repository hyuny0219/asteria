# Known issues / 미완성 범위

새 그림이 있다고 해당 시스템이 완성된 것은 아닙니다. 아래는 이번 MVP에서 **완료로 보고하지 않는** 항목입니다.

## 애니메이션 (P1 — 미완성)
- **세린 기본형**: 인계된 8개 키 포즈(대기/걸음/준비/찌르기/회수/피격/시전/승리)를 공격 단계에 맞춰 전환하고, 호흡·전진·밀림을 트윈으로 더했습니다. 중간 프레임·보행 주기·머리카락/옷자락 변형은 없습니다. 걷기는 2포즈 교대 + 제자리입니다.
- **승급 2갈래**: 분기별 전신 원화가 1장씩뿐이라, 승급 후에는 모든 상태에서 그 1장에 전진·흔들림·무기 궤적(호)만 더합니다. 기본 포즈를 쓰면 공격 중 의상이 바뀌어 동일성이 깨지기 때문입니다. **분기 전용 전투 시트(방패 범위·대검 궤적)는 미제작**입니다.
- **일반 적 6종·보스 3종**: 단일 정지 그림에 압축/기울임/돌진/점멸/페이드 변형만 적용했습니다. 07 명세의 대기/이동/공격/피격/사망 프레임은 없습니다. 보스의 패턴별 전용 포즈도 없습니다.
- **교관 분신**: 세린 대기 포즈를 좌우 반전 + 흑백·밝기 필터 + 반투명으로 그립니다(07 명세대로 별도 완성 캐릭터로 집계하지 않음). Canvas `filter`는 일부 모바일에서 느릴 수 있으며 실기기 미측정입니다.
- 승급 연출은 현재 모습 → 새 원화 크로스페이드입니다(08 타임라인 시간은 지킴).
- 피해·궁극기·보상은 전투 이벤트에서만 처리되며 위 연출과 무관합니다(단위 테스트로 15/30/60FPS 동일 확인).

## 에셋
- `assets/runtime/*.webp`는 보드에서 개체별로 잘라 반투명 배경 안개를 제거·트림·축소한 **정적 스프라이트**입니다(검수 시트 `docs/qa/assets_*.png`). 2048 아틀라스로 패킹하지 않았고 개별 파일로 로드합니다(런타임 그림 약 1.3MB + 폰트 약 340KB).
- 찌르기 포즈의 검 끝은 원본 셀 가장자리(x=1536)에 닿아 원본 단계에서 잘려 있습니다.
- 가시 슬라임 군주(B01) 오른쪽 윤곽은 보드에서 모래 수호자 망토와 붙어 있어 직선으로 남습니다. B01/B03은 검토용 영역(`asset_regions.json`)이 개체를 자르고 있어 넓힌 영역으로 다시 추출했습니다(`sprites.json`의 `reviewRect` 참고).
- 히트박스는 불투명 몸체 기준 근사값이며 판정에는 쓰지 않습니다(MVP 판정은 전열 1체 + 궁극기 전체).
- 배경 3장은 단일 레이어입니다. 패럴랙스·반복 타일 없음. 재료 던전은 폐광 배경 + HUD 표기만 쓰며, 명세의 금빛 광맥·던전 표식 오버레이는 없습니다. 교관 시련은 성당 배경을 재사용합니다.
- 확장용 아이콘(보석·전설 상자·별 열쇠)은 사용하지 않습니다.

## 밸런스 (실험값)
- `docs/BALANCE_CHANGES.md`의 값은 스크립트 플레이어 시뮬레이션으로 맞춘 **가설**입니다. 실제 유저 데이터가 없으므로 D1/D7/D30을 주장하지 않습니다.
- 고대 사막 보스는 첫 도전 승률이 낮습니다(시뮬레이션 도전 승률 약 22%, 런당 4회 시도).
- 폐광 몬스터 레벨은 21–33, 폐광 파수꾼은 Lv 32입니다(승급 전 Lv 30 잠금에서 깰 수 있게). 지역 표시는 권장 Lv 21–35를 유지합니다.
- 던전 실패 시 입장권은 소모되고 광석 30%를 받습니다(명세에 없어 정한 규칙). 재료 던전은 첫 보스 처치 후 열립니다.
- 임시 보관함 100칸을 넘는 신규 장비는 분해 값만큼 광석으로 전환하고 개수·광석을 화면에 표시합니다(방치 정산의 초과 전환 규칙을 전경에도 적용). 자동 삭제는 없습니다.

## 저장·보안
- 로컬 저장(IndexedDB / localStorage)은 개발 도구로 수정할 수 있습니다. **치트 방지 아님.** 기기 시계를 바꾸면 방치 시간·입장권 충전을 조작할 수 있습니다(역행은 0 처리·진단 기록, 7일 초과 공백은 기록 후 12시간 상한).
- 기기 이동·백업은 내보내기 파일로만 됩니다. iOS Safari는 오래 방문하지 않은 사이트의 저장소를 지울 수 있습니다(ITP) — 미검증.
- 저장 실패는 개발 설정의 "실패 시뮬레이션"으로만 검증했습니다. 실제 용량 초과(QuotaExceeded)·브라우저 저장 차단은 실기기에서 확인하지 않았습니다.
- 다중 탭은 Web Locks로 한 탭만 쓰게 하고 revision 충돌도 검사합니다. Web Locks가 없는 브라우저용 localStorage 하트비트 대체 경로는 브라우저 테스트를 하지 않았습니다.

## UI·접근성
- 22개 화면을 실제 상태에 연결했고 Chromium에서 390×844/360×700/412×915 가로 넘침 0건입니다. **실제 iOS Safari / Android Chrome, 터치 사용성, 스크린 리더, 저사양 30fps, 배터리는 미검증**입니다.
- 200% 텍스트는 CSS 글꼴 크기로만 확인했습니다(OS 글꼴 확대 미검증).
- 전투 Canvas 내용은 보스 강공 경고만 `aria-live`로 읽어 줍니다. 전투 전체를 스크린 리더로 따라가기는 어렵습니다.
- 정적 시안 대비 차이: 광고 버튼(+25% "후속 시안")은 아예 표시하지 않습니다. 시안의 카드형 스크롤 대신 08 명세의 높이표(52/40/220/64/56/312/56)로 배치했습니다. 차이 목록은 `docs/IMPLEMENTATION.md`.
- 효과음은 WebAudio 합성 임시음입니다. BGM·보이스 없음.

## v4 확장 (기획서 전체) — 임시 처리
- **그림**: 4클래스·8갈래 3차까지의 외형, 몬스터 M07–M20, 보스 B04–B10 + 탑 수호자, 지역 4–10·탑 배경, 새 스킬·각인·탑/레이드 아이콘을 모두 생성 그림으로 교체했습니다(`assets/source/generated/`, 추출 `tools/extract_v4.py`·`extract_v4b.py`). 색조 임시본(`tint`/`bgTint`)은 남은 곳이 없습니다. 예외: 황금 금고·스킬북 서고 던전은 여전히 사막·성당 배경을 재사용합니다(금고는 사막 배경에 금빛 색조).
- 기획서에서 의도적으로 뺀 것: 광고 무료 소환·실결제, 포션·MP·마을 귀환, 사냥 범위·이동 속도 옵션, 사망 EXP 페널티, 리젠 8초, 가방 40칸, 오프라인 8시간·50%(v3 12시간·75% 유지). MP 대신 WIS는 쿨타임 감소. 스킬은 6개 중 4개 대신 슬롯 5개.
- `tools/balance_sim.mjs`·`tools/branch_parity.mjs`는 v3(Lv 35) 기준 도구로 남겨 두었고, v4는 `tools/balance_sim_v4.mjs`를 씁니다.
- 레이드 보스는 120초 점수제라 쓰러뜨리지 않아도 보상이 나옵니다. 영웅이 쓰러져도 그때까지 피해로 등급이 정해집니다.

## v4 UI — 임시·미완성
- 엘레나·리라·녹스는 생성 보드(`assets/source/generated/*_board.png`)에서 잘라 쓴 **정지 그림 1장**(기본 / 1차 갈래)입니다. 세린 같은 8키 포즈가 없어 공격은 전진 트윈(근접은 궤적 호)으로만 표현합니다. 2·3차 승급 외형도 차수마다 정지 그림 1장입니다.
- 생성 보드의 배경 제거는 Higgsfield 배경 제거 결과(`*_alpha.png`)의 알파를 썼습니다. 아이콘 시트는 단색 배경 색 거리로 분리했습니다(`tools/extract_v4.py`). 일부 망토 끝·머리카락 가장자리는 배경 제거 품질에 따라 약간 거칠 수 있습니다.
- 클래스 카드·얼굴·일러스트는 같은 보드에서 잘랐습니다. 일러스트(2:3)는 보드 높이 한계로 머리 위 여백이 적어 표시 위치를 위쪽으로 맞췄습니다.
- 새 몬스터 14종·보스 7종은 생성 보드에서 잘라 쓴 **정지 그림**이고(대기·공격·피격 프레임 없음, 기존처럼 압축·돌진·점멸 변형만), 배경은 단일 레이어입니다. 장갑·신발·반지는 등급별 전용 아이콘(일반/고급/희귀/영웅 이상)으로 바뀌었고, 예전 저장의 장비도 불러올 때 아이콘을 고칩니다(장화가 투구로 보이던 문제 수정).
- 원거리 클래스의 공격은 화살·마법 그림 없이 빛줄기 선으로 표시합니다.
- 화면 크기는 선배 요청으로 v3 기준(48px/16px)보다 작습니다(QA_REPORT 참고).

## v4 그림 적용 (2부)
- 모든 비세린 캐릭터(엘레나·리라·녹스, 승급 외형 24종)와 새 몬스터·보스는 포즈 프레임이 없는 정지 그림입니다. 리깅·프레임 애니메이션은 후속 작업입니다.
- 생성 보드의 평면 배경은 색 거리로 지우고, 어두운 부분이 지워지는 보드는 Higgsfield 배경 제거 결과(`*_alpha.png`)와 합쳐 썼습니다. 연기·불꽃 가장자리는 반투명으로 남습니다.
- 같은 등급 이상(영웅·전설·신화)의 장갑·장화·반지는 아이콘 하나를 함께 씁니다.
- `tools/browser_qa.cjs`의 QA용 상태 변경은 정기 저장이 진행 중이면 잠시 뒤 다시 시도합니다. 보스·레이드 '포기'를 정기 저장 도중 누르면 결과 저장이 그 저장과 겹쳐 '다른 탭' 화면이 뜨던 문제를 고쳤습니다(저장이 끝난 뒤 포기 처리).

## 자동 성장·키 포즈 (v4 3부)
- 성장 탭은 확인 전용입니다(선배 요청). 골드 강화 5종은 사냥 중 2초마다 자동 구매되고, 레벨업 포인트는 클래스 추천대로 자동 분배됩니다. 수동 강화·포인트 직접 분배·초기화는 없습니다.
- 자동 강화는 2차 승급 골드(Lv 55부터)와 스킬북이 모인 스킬의 레벨업 골드를 남겨 둡니다. 상점의 골드 상품·스킬 레벨업은 직접 눌러야 합니다.
- 엘레나·리라·녹스 기본 외형은 8 키 포즈(대기·걸음·준비·공격·회수·피격·시전·승리)로 움직입니다. 키 포즈 전환이며 연속 프레임 애니메이션은 아닙니다. 승급 외형(1~3차)은 여전히 정지 그림 1장 + 트윈입니다.
- 마법사 포즈판의 마법 광채(지팡이 빛·마법탄)는 배경 제거 때 일부 지워졌습니다. 공격 순간은 기존 사격 궤적 효과로 보완합니다.
