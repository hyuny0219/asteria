## 우편함
- 진입: 메뉴 › **우편함** 타일(받을 우편이 있으면 빨간 점), 받을 우편이 있을 때 상단 상태줄의 **편지 아이콘**(숫자 배지).
- 우편 = 제목 · 본문 · 보낸이(운영자/시스템) · 도착 시각 · 보상 · 받음 여부.
- 보관: 받지 않은 우편은 **도착 후 30일**에 사라짐(사라진 수는 우편함 아래에 표시). 받은 우편은 **7일 뒤** 정리. 최대 100통.
- **받기 / 모두 받기**: 보상 지급은 트랜잭션 하나. 저장이 끝난 뒤에만 보상 연출 창이 뜸.
- 보상 종류: 골드 · 보석 · 강화 광석 · 장비/스킬 뽑기권 · 각성석 · 별의 파편 · 정령 알 · 동료 먹이 · 던전 입장권, 장비 1개(`item: { slot, rarity }`, 받을 때 생성, 우편 id로 시드 고정).
- `sendMail(state, { title, body, sender, rewards, now })`: 우편을 넣는 유일한 함수. 운영 우편·쿠폰 보상이 사용. 앞으로 "보관함이 가득 차 못 받은 보상"도 여기로 보내면 됨.

## 운영 우편 (`src/data/mail.js`)
- 정적 목록: `id, from, to(KST), minLevel?, title, body, rewards`.
- 게임을 불러올 때(정기 정리와 함께 저장) 기간 안이면 **프로필당 1번** 배달 (`mail.delivered[id]`).
- 기본: **환영 우편** (보석 300 · 장비권 5 · 스킬권 3, 상시) / **v8 업데이트 기념** (보석 500 · 장비권 10 · 스킬권 5, 2026-11-07 ~ 11-30 KST).

## 쿠폰 (`src/data/coupons.js`)
- 우편함 맨 위 **쿠폰 입력**. 대소문자·띄어쓰기·하이픈·밑줄 무시.
- 코드는 평문이 아니라 `SHA-256("asteria-nocturne-v9:" + 정규화 코드)`만 저장. 보상 · 만료(`until`) · 프로필당 1회.
- 성공하면 보상이 **"쿠폰 보상" 우편**으로 도착. 실패 사유: 없는 코드 / 기간 끝 / 이미 사용 / 빈 입력.
- 새 쿠폰: `node tools/make_coupon.mjs <CODE>` → 출력된 hash 줄을 `COUPONS`에 추가.
