# GPT 요청서 O — 스킬

## O6. 진화 스킬 아이콘 (v16)

전직마다 진화하는 기본 스킬 3개 + 궁극기의 아이콘입니다. 지금은 기본 아이콘에 갈래색 테두리와 단계 배지(Ⅰ~Ⅳ)를 씌워 쓰고 있어서, **받기 전에도 게임은 돌아갑니다.** 받은 PNG는 아래 파일 이름 그대로 올려 주면 추출기로 넣습니다(`sprites.json → skills`).

## 공통 조건 (맨 앞에 붙이기)

```
[아스테리아 공통 아트 조건 · 아이콘]
- 화풍: 지금까지의 스킬 아이콘(스킬 화면 S0~S5, G00~G23, K01~K15)과 같은 비도트 다크 판타지 반실사 아이콘. 픽셀아트·치비 금지.
- 배경: 진짜 투명 PNG(알파). 안 되면 아주 어두운 단색(#1c1726) 평면.
- 빛 번짐(헤일로)·바깥 광채·그림자 금지 — 잘라낼 때 가장자리가 지저분해집니다. 빛은 문양 안쪽에만.
- 글자·숫자·테두리·워터마크 없음 (등급 테두리와 단계 배지는 게임이 따로 그립니다).
- 판 1536×1024, 8열×4행 같은 크기 칸(192×256 칸, 아이콘은 칸 가운데 정사각 약 160×160 안에), 칸끼리 겹치지 않게, 칸마다 여백 8% 이상.
- 같은 행(=같은 스킬)은 단계가 오를수록 더 화려해지되 같은 모티프를 이어 갑니다: 1차 단순 → 2차 색·장식 추가 → 3차 형태가 커지고 문양 → 4차 초월(별빛 파편·떠 있는 장식).
```

## 판 구성

한 직업에 한 판(4장). **행 = 갈래 × 스킬, 열 = 단계**. 1~4열 = 첫 갈래 1~4차, 5~8열 = 둘째 갈래 1~4차. 행 1~4 = 기본 스킬 1·2·3 · 궁극기.

|---|---|---|---|
