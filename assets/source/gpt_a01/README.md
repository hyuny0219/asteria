## Claude에게 전달할 지시

1. `atlas.json`의 파일명과 `frames[].rect`를 게임의 승급 외형 ID에 연결한다. 프로젝트 내부 ID는 실제 코드에서 확인한다.
2. 8장을 8fps로 반복하는 애니메이션으로 해석하지 않는다. 대기/걸음/공격/피격/승리 상태에 대응하는 키 포즈다. 공격은 windup → contact → recovery 순서로 사용한다.
3. contact 진입 시 기존 전투 판정 이벤트를 한 번 발생시킨다. 이미지 재생 횟수가 피해 횟수를 바꾸지 않게 한다.
4. 원본 셀 크기는 유지하고, 화면 출력 크기는 캐릭터의 실제 보이는 키를 기준으로 조절한다. 빈 여백을 잘라낸 뒤 셀마다 제각각 확대하지 않는다.
5. `suggestedPivot`는 알파 윤곽 하단에 기반한 초기값이다. 무기/이펙트가 신발보다 아래로 내려오는 포즈에서는 신발 위치를 직접 확인해 보정한다. 수평 기준점도 골반 위치로 최종 조정한다.
6. 반투명 가장자리를 보존하는 일반 알파 합성을 사용한다. 검은색/흰색 색상 키 방식으로 배경을 제거하지 않는다.
7. `QA_REPORT.md`의 잔여 항목을 확인한 뒤 실제 게임 배경에서 최종 검수한다.

## 제작 기록

내장 이미지 생성으로 원화 참조 생성 및 여백 확대 보정을 수행했습니다. 생성/수정 프롬프트는 `prompts.json`, `revision_prompt.txt`에 포함했습니다. 자동화 코드로 PNG 픽셀을 수정하지 않았습니다. 각 시트는 연속 애니메이션용 중간 프레임이 아니라 키 포즈입니다.
