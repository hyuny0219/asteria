# A01 검수 결과

## 통과

- 8개 PNG 모두 정상 디코딩, 1536×1024, RGBA.
- 64셀 모두 alpha > 32인 보이는 윤곽 기준 좌우 31px, 상하 41px 이상 여백 확보(각 축 8% 이상).
- 초기 검/망토/활의 셀 경계 접근 문제를 전체 축소 보정으로 개선.
- 오른쪽 방향의 8개 동작과 전신 확인. 셀 간 보이는 개체의 겹침 없음.
- 투명 픽셀 존재. 알파 범위는 모든 파일 0~254.
- 미리보기 8개 이미지 로딩, 클래스/포즈 선택, 순서 재생 동작 확인. 브라우저 JS 오류 없음.

## 잔여 조건 — 완전한 생산용 마감으로 판정하지 않음

- alpha 1~32의 미세 잔여 픽셀이 빈 영역에 존재한다. 모든 비영 알파 픽셀까지 포함하는 엄격한 8% 여백/완전 무헤일로 조건을 충족했다고 주장하지 않는다. 실제 배경 위에서 밝은 테두리와 마법 주변 잔상을 확인해야 한다.
- 발 기준선은 포즈/행/클래스마다 수 px 이상 차이가 있다. atlas의 하단 기반 피벗은 초깃값이며, 공격 효과와 검 끝을 발로 오인하지 않도록 최종 수동 조정한다.
- 의복 장식·얼굴 세부는 생성 과정에서 변동할 수 있다. 원화와 픽셀 단위 동일 외형은 보장하지 않는다.
- 여백 확보 후 보이는 인물 키는 대략 250~300px 수준이다. 원화 확대 감상보다는 모바일 전투 표시에 적합하다.
- 이동 중간 프레임, 관절 리깅, 실제 게임 전투 연결, iPhone/Android 실기기 검증은 포함하지 않는다.

파일/셀별 수치는 `qa.json`. 수치는 PNG를 읽어 측정했으며 픽셀을 변경하지 않았다.
