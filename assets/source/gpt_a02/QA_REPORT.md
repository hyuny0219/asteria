# A02 검수 결과

- PNG 16장 모두 1536×1024 RGBA, 정상 디코딩. 4×2 총 128키 포즈.
- alpha>32 윤곽 기준 128셀 모두 좌우31px·상하41px 이상 여백 통과. 상세 측정은 qa.json.
- 모든 파일 알파 범위 0~254. 초기 팔라딘의 불투명 배경 문제와 일부 무기 여백 부족을 재생성으로 보정.
- 브라우저 16개 이미지 로딩 및 16외형 선택 확인, 포즈 재생 상태 전환, JS 오류0.
- 원본 전체 보드와 바둑판 합성 미리보기 육안 확인.

## 적용 전 남은 사항
- alpha1~32의 잔여 픽셀이 있어 모든 비영 알파를 포함한 엄격한 무헤일로·8% 여백 조건을 완전히 충족했다고 주장하지 않는다.
- 외형별 실제 인물 크기가 다르므로 클래스 간 화면 키를 맞춰야 한다. 특히 여백 재보정한 팔라딘·팬텀·페이트위버가 작다. 같은 외형의 포즈에는 공통 배율을 사용한다.
- suggestedPivot는 효과/무기를 포함할 수 있는 자동 윤곽 기준이다. 신발 접지점을 직접 확인해 수동 보정한다.
- 8키 포즈이며 중간 프레임/리깅은 없다. 게임 로직 연동, 모바일 실기기 성능 검증은 포함하지 않는다.
- 신규 제안 외형으로 세부 장식·손·활시위·얼굴의 완전한 일관성은 보장하지 않는다. 원화 설계 의도와 최종 이미지 사이의 작은 차이는 최종 아트 마감 대상이다.
