# ASTERIA / NOCTURNE — A02 Claude 전달 패키지

2·3차 승급 외형을 새로 디자인한 16종 × 8키 포즈 = 128포즈 패키지.
A01의 1차 8종과 합치면 승급 24종이다. 이 ZIP에는 A02만 포함하며 기존 A01/v4를 덮어쓰지 않는다.

## 시작
압축 해제 후 preview.html을 열어 클래스와 포즈를 선택한다. 순서 재생은 키 포즈 확인용이며 완성된 연속 애니메이션이 아니다.

## Claude 적용 지시
- DESIGN_GUIDE.md → QA_REPORT.md → atlas.json 순서로 읽는다.
- 각 PNG는 1536×1024, 4열×2행, 셀 384×512이다. atlas.json의 rect를 그대로 사용한다.
- 대기 / 걸음 / 공격 준비 / 타격 / 회수 / 피격 / 스킬 / 승리 순서다.
- 각 시트의 첫 칸이 이번 신규 디자인의 기준 대기 원화다. 별도 고해상도 전신 원화 파일은 없다.
- 2차와 3차의 시스템 ID를 기존 게임 데이터와 대조한다. 클래스 영문 이름만 보고 저장 구조를 변경하지 않는다.
- 공격은 windup → contact → recovery 상태로 연결한다. contact 진입에서 기존 타격 이벤트를 1회 실행하며 이미지 재생 횟수가 공격 횟수를 바꾸지 않게 한다.
- 사망 포즈는 이 요청 범위에 없다. victory나 hit를 사망 이미지로 오인하지 않는다.
- suggestedPivot는 alpha>32 하단을 기준으로 산출한 초깃값이다. 신발보다 낮은 검/마법 효과가 있는 경우 발 기준으로 수동 보정한다. 수평 기준도 골반 위치에 맞춘다.
- 셀마다 따로 확대하면 몸 크기가 흔들린다. 동일 외형에는 공통 배율을 사용하고 위치만 보정한다.
- 기존 1차의 성인 얼굴/헤어를 참고한 신규 디자인이다. 기존 미제공 2·3차 원화와 동일하다고 가정하지 않는다.
- 반투명 경계를 보존하는 일반 알파 합성 사용. RGB 검정/흰색 색상 키로 배경을 제거하지 않는다.
- 실제 게임 배경에서 손/무기, 활시위, 발 미끄러짐, 단계 간 외형 차이를 마지막으로 확인한다.

## 제작 기록
내장 이미지 생성으로 개별 16시트를 제작했다. prompts.json은 디자인 설명과 원본 프롬프트를 포함한다. PNG 픽셀에 코드 기반 이미지 보정을 가하지 않았다. 원본 아틀라스의 대기 포즈가 외형 기준이며, 미리보기는 원본 파일을 직접 사용한다.

B~H의 이펙트/몬스터/보스/동료/아이콘/배경 작업은 이번 패키지에 포함하지 않는다.
